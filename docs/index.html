Features

Everything stays focused on one job: making Twitch VOD chat usable with YouTube uploads.

Precise time sync

Use a fixed offset between the Twitch chat timeline and YouTube. Nudge it by one second or enter a full time value, then save it back into the JSON.

Large chat files

Large TwitchDownloader JSON files are loaded incrementally instead of being turned into one giant JavaScript JSON object at once.

Chat search

Search the replay to find recognizable moments and use them as practical sync points when lining up a new upload.

Twitch emotes

Supports first-party Twitch emotes and third-party BTTV, FFZ, and 7TV emotes when the chat data/API information is available.

Appearance controls

Clean chat, show or hide timestamps, split messages for readability, adjust opacity, and hide the visible scrollbar while keeping the chat scrollable.

Eight languages

The popup and overlay UI are translated for English, Spanish, French, Japanese, Korean, Portuguese, German, and Italian.

Popup + overlay controls

Load chat, save offset, adjust synchronization, and change appearance from the Chrome toolbar popup. The same preferences stay synchronized with the in-page overlay.

Local processing

Your Twitch chat JSON is processed in the browser. The extension has no account system, analytics, ads, or remote JavaScript.

Video-page only

The chat overlay only appears when you are viewing a YouTube video. It stays hidden while you browse other YouTube pages.

Simple installation

Download the release ZIP, unzip it, enable Developer mode, and use “Load unpacked” in Chrome's extensions page.

Installation

Download the extension from GitHub and install it in Chrome.

1

Download

Open the GitHub Releases page and download the latest .zip release.

2

Load unpacked

Unzip it, open chrome://extensions, turn on Developer mode, and choose Load unpacked.

3

Use on YouTube

Open a YouTube video page, then load your TwitchDownloader chat JSON through the extension toolbar.

Privacy

Designed to work locally instead of sending your chat logs to a service.

Does the extension upload my chat JSON?

No. The core chat file is loaded and processed locally in the browser. Third-party API requests are only used to retrieve public emote information when needed.

Does it collect analytics or require an account?

No. There is no analytics system, advertising system, account system, or remote JavaScript execution in the extension.
